# 変更履歴

計測方法や集計定義の変更を記録します。数字が前月と比べて動いたとき、
実態が変わったのか計測が変わったのかを区別できるようにするためです。

## 未リリース

- 初回公開に向けた準備中。P1（母集団確定）から P8（公開）までの工程を実装
- DMARC の実効強度を RFC 7489 と RFC 9989 の両方で計算するようにした
- Organizational Domain を Public Suffix List と Tree Walk の両方で解決するようにした
- `p=quarantine` に `reject` と同じ強度ラベルを付けていたのを分離した。
  これにより「実効 reject」の集計から quarantine が外れる
- 率の分母を「観測できたドメイン」に変更した。それ以前は計測対象の全ドメインを
  分母にしており、観測に失敗したドメインが未対応として数えられていた
- 業種別集計のセル秘匿を2段階にした。5社未満のセルを束ねる際、束ねた対象が
  1つだけだと合計から復元できるため、次に小さいセルも束ねる

## 記録の方針

集計定義を変えた場合、その月の数字と前月の数字は直接比較できません。
その旨をここに明記します。過去の集計は遡って作り直さず、履歴として残します。
