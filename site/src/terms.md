# 免責事項・利用規約

## このサイトの位置づけ

本サイトは標準準拠の計測であり、総合的セキュリティ評価ではありません。

掲載しているのは、公開されている DNS レコードから読み取れる事実と、
辞書との照合による推定です。各社のメールセキュリティの水準や、
組織全体の情報セキュリティを評価するものではありません。

## 免責

- 観測は特定時点の DNS 応答に基づきます。観測後に設定が変わっている場合があります
- DNS の応答が得られなかった場合を「設定が無い」とは扱っていませんが、
  観測の失敗を完全に排除できるわけではありません
- 推定には確度を付けていますが、誤りが含まれる可能性があります
- 検出できない構成があります（[方法論](/methodology)に記載）
- 本サイトの情報を用いて行った判断の結果について、責任を負いません

## データのライセンス

集計結果（`gold/` の Parquet および本サイトの JSON / CSV）は **CC0 1.0** で
公開しています。

一次データの出典表記は各提供元の規約に従ってください。

```js
const meta = FileAttachment("data/meta.json").json();
display(html`<ul>${(meta.attribution ?? []).map((t) => html`<li>${t}</li>`)}</ul>`);
```

コードは Apache-2.0 です。

## 計測の方針

- 権威 DNS への負荷を抑えるため、同じ名前を繰り返し引かず、レート制御を行っています
- スクレイピングを禁じている提供元のデータは使っていません。API 経由のみです
- 個人名を含むメールアドレスは収集も保存もしていません。DMARC のレポート宛先は
  ドメイン部分だけを保持しています

## 計測対象から外した分の扱い

計測対象から外すと決めたドメインには、以降 DNS の問い合わせを行いません。
除外した件数は各月の実行記録に残しています。**黙って分母から外すと、
率が理由の説明できない形で動きます。**
