# 検索結果に出さない。**ただし巡回は許す。**
#
# 直感に反するが、`Disallow: /` と noindex を併用してはいけない。
# Disallow はクローラに「取りに来るな」と言うだけで、索引から外すこととは
# 別である。取りに来られなければ noindex（X-Robots-Tag / meta）を読めない
# ので、**他サイトからリンクされていれば URL だけが検索結果に残りうる。**
#
# 索引に載せたくないなら、巡回させたうえで noindex を読ませるのが正しい。
# 実体は _headers の X-Robots-Tag と、各ページの meta robots にある。
#
# sitemap は意図的に置いていない。出すべき状態になったらここに書く。
