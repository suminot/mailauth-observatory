# gold

集計結果（P7 の出力）を `month=YYYY-MM/` の形で置く。ここだけは Git にコミットする。

bronze / silver は `data/runs/` に置き、Git には入れずに Cloudflare R2 へ退避する
（DESIGN.md 第4章）。git-scraping パターンの既知の弱点である履歴肥大化を避けるため。
ある事例では80MBのデータで4年運用後にリポジトリが1GB超に膨張している。

gold は bronze から完全に再生成できなければならない（原則1）。ここにあるファイルを
失っても、bronze さえ残っていれば作り直せる状態を保つこと。

## 公開ライセンス

gold として公開する Parquet / CSV は **CC0** で出す。個人研究でバス係数が1である以上、
「自分が続けられなくなっても誰かが引き継げる」ことが最大の保険になるため
（DESIGN.md 第11章 未解決事項3の推奨案）。

ただし OpenINTEL 由来のデータを混ぜる場合は CC BY-NC-SA の継承条項が波及しうるため、
その系列だけは別ファイル・別ライセンスで分離して配布すること。
