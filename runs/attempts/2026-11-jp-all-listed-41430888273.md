## 警告

### p1_population

- `DELISTED_WITH_SECURITIES_CODE` ×2: 証券コードはあるが、コードリストの上場区分が「非上場」の提出者を母集団に入れていない
- `ENRICH_SKIPPED_HOUJIN_BANGOU`: MAILAUTH_HOUJIN_BANGOU_APP_ID が未設定のため商号・所在地の裏取りをしていない
- `WIKIDATA_NAME_MISMATCH` ×3: securities_code で鍵は当たったが社名が一致しない項目を 3 件使わなかった。**別の会社のサイトを紐づけないための歯止めである。**多すぎるなら鍵か国の絞り込みを見直すこと
- `NO_PREVIOUS_RUN`: 前月 2026-10 の entities.parquet が無いため差分を計算していない
- `ACCEPTANCE_MISSING_RATE`: official_url の欠損率 11.6% が閾値 10.0% を超えている

### p2_candidates

- `PHASE_BUDGET_EXCEEDED` ×3492: この調子では持ち時間（240 分）に収まらないと分かったので、320 社まででやめた。見込みは全体で 4.1 時間だった。**残り 3492 社は「候補ゼロ」ではなく「まだ測っていない」。** 同じ run_id で流し直すと、CT のキャッシュに積み上がって いる分はそのまま使われるので続きから進む
- `DOMAIN_SHARED_BY_ENTITIES`: 同一ドメインが複数企業に紐づいている。持株会社・グループ共用の可能性
- `UNALIGNED_RUA_TARGET` ×22: 自社ドメインでない rua 宛先があった。**候補にしていない。** 第三者のレポート処理サービスであり、その企業の送信ドメインではない。ベンダー名が分かれば configs/vendors/dmarc_rua_vendors.yaml に足すと P6 の dmarc_vendor 推定が埋まる
- `ACCEPTANCE_ZERO_CANDIDATES`: 候補ゼロの企業が 7.2% で閾値 5.0% を超えている

### p4_measure

- `RESUMED_FROM_EXISTING_BRONZE` ×3441: 同じ run の bronze に 3441 ドメインぶんが既にあったため測り直していない。**「観測していない」のではなく「前回の実行で観測済み」である**
- `BRONZE_APPENDED_TO_EXISTING` ×6: 同じ run に既存の bronze があったため、上書きせず新しいパートに追記した（bronze は不変・追記のみ）。--resume なので、既に測り終えたドメインは測り直していない

### p5_parse

- `BRONZE_OUTSIDE_MEASURED_SET` ×3140: 同じ run の bronze に、いまの P3 が計測対象にしていないドメインがあった（前の試行の残り）。facts に入れていない
- `MX_UNREACHABLE` ×3: どの MX ホストにも宛先が無い（名前が無い、またはアドレスが無い）ドメイン。**このドメイン宛のメールは届かない。** 終わったサービスや綴りの誤りを指したままのものがある

### p6_infer

- `NO_STALE_HISTORY`: 前月の inferences.parquet が無いため stale の連続月数を引き継げない。3 か月連続の判定は今月を1か月目として数え直す
- `UNKNOWN_MX_HOSTS` ×16: 辞書に無い MX ホストが 16 種、32 ドメインぶんある。**全部を一覧に出している。****自社ドメイン配下の MX 58 ドメイン（50 社）は一覧から外している** ── 辞書に足してもその1社にしか効かない。**名前の無い MX ホスト 5 ドメインぶんも外している**（製品ではない。P5 の MX_UNREACHABLE を見ること）。頻度順の上位を手で辞書に追記すると推定率が上がる（DESIGN.md P6 実装メモ）
- `SECURITY_GATEWAY_UNDETECTABLE` ×309: セキュリティ製品を DNS 上で検出できなかったドメイン。**理由の内訳: api_mode_product 256件、self_hosted_mx 47件、spf_flattened 6件、tenant_placeholder_mx 2件。** どれも「使っていない」と解釈してはならない

### p8_publish
